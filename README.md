# System Info Script

This Bash script collects important system information from an Ubuntu Server. It outputs details such as hostname, OS version, uptime, kernel, CPU, memory, network interfaces, disk usage, and recent errors in logs.

##What It Shows
- System Hostname
- Operating System details
- System Uptime
- Linux Kernel Version
- CPU Info
- Memory Usage (free/used)
- Network Interfaces (IP and MAC)
- Filesystem Usage
- Last 5 system log errors
- ##Usage

Make sure the script is executable:

```bash
chmod +x system_info.sh
